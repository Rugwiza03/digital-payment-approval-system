# Digital Payment Approval System

A modern, web-based platform for managing and approving digital payment requisitions with security, speed, and efficiency.

## 🚀 Features

- Secure user authentication using **NextAuth.js**
- Interactive dashboard for viewing and managing payment requisitions
- Role-based access control for different user permissions
- Dynamic requisition form with multi-step approval workflow 
- Built with **Next.js**, **Prisma**, and **Tailwind CSS** 

## 🛠 Tech Stack

- **Frontend**: React, Next.js, Tailwind CSS  
- **Backend**: Next.js API Routes  
- **Database**: PostgreSQL (managed via Prisma ORM)  
- **Authentication**: NextAuth.js  

## 📦 Installation

To get started locally, run the following:

```bash
git clone https://github.com/Rugwiza03/digital-payment-approval-system.git
cd digital-payment-approval-system
npm install
```

Then start the development server:

```bash
npm run dev
```

> Ensure you have a `.env` file configured with your database and authentication credentials.
